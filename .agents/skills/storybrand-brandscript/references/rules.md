# BrandScript lint rules

Flag any of these before saving.

## Must pass

- [ ] Exactly **one** customer desire
- [ ] Exactly **one** villain
- [ ] Villain is a root source (not a feeling), relatable, singular, real
- [ ] External, internal, and philosophical problems all filled
- [ ] Philosophical uses *ought* / *shouldn't*
- [ ] Empathy statement present (customers won't know you care until you tell them)
- [ ] Authority is light (~3 proofs), not a brag wall
- [ ] Process plan has **3–6** steps (prefer 3–4); plan is named
- [ ] One direct CTA and one transitional CTA
- [ ] Failure: about **3** bullets (salt, not fearmongering)
- [ ] Success: many specific bullets (not "exhale success" vagueness)
- [ ] Identity From → To present; "To" written first
- [ ] One-liner has Character + Problem + Plan + Success
- [ ] No brand-as-hero phrasing ("we are industry leaders who…")
- [ ] No inside jargon a stranger wouldn't get

## Common fails (from the book)

| Smell | Fix |
|---|---|
| "Inhale knowledge, exhale success" | Tie to survival: status, tribe, time, money, meaning |
| Villain = "frustration" / "stress" | Name the root source that causes it |
| Missing internal problem | Ask what the customer fears about themselves |
| 10+ plan steps | Group into 3–4 phases |
| 10–20 testimonials | Keep ~3 short ones |
| Brand history above the fold | Cut; hitchhiker only asks where you're going |
| Success = "excellence" / "solutions" | Specific destination: "a room that finally feels finished" |
