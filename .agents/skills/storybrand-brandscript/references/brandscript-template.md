# BrandScript template

Save to `.agents/brandscript.md` with these exact headings. Other skills parse by heading name.

```md
# BrandScript

**Scope:** [whole brand | division | product | segment] — [name]
**Updated:** [date]

## One-liner

[Character + Problem + Plan + Success]

## Character

**Wants:** [one desire, survival-linked]

## Problem

**Villain:** [singular, root source, relatable, real]
**External:** [tangible issue]
**Internal:** [how it feels — usually "Do I have what it takes?"]
**Philosophical:** [ought / shouldn't]

## Guide

**Empathy:** [we understand / nobody should have to / like you, we're frustrated by…]
**Authority:** [~3 testimonials, stats, awards, or logos — competence, not bragging]

## Plan

**Name:** [e.g. easy installation plan]
**Process:**
1. …
2. …
3. …
**Agreement:** [optional — fears countered with promises]

## CTA

**Direct:** [Buy / Schedule / Call / Register…]
**Transitional:** [lead magnet or low-risk next step]

## Failure

- …
- …
- …

## Success

- …
- …
- …

## Identity

**From:** …
**To:** …

## Decisions and open questions

- …
```
